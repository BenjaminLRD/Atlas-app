**Atlas** is a Flutter fitness and wellness app for Android: workout tracking, GPS run/ride tracking, steps and health data, nutrition logging (barcode, photo, manual), a community and an AI coach, with a Supabase backend and Gemini reachable only through a server-side function. Built for UCS503 Software Engineering Lab (Thapar Institute, Group 3Q23).

## Which file should I download?

| File | For | Size |
|---|---|---:|
| **app-arm64-v8a-release.apk** | **Almost all modern Android phones. Choose this one.** | 66 MB |
| app-armeabi-v7a-release.apk | Older 32-bit ARM phones | 59 MB |
| app-x86_64-release.apk | Android emulators on a PC | 69 MB |

Requires Android 8.0 or newer. Version 1.1.0 (build 2), built 18 November 2026.

## Install

1. Download the APK on your phone and open it.
2. If Android blocks it, tap Settings and allow installs from this source (your browser or file manager), then tap Install.
3. Open Atlas and choose "Explore in Showcase Mode" to try it without an account.

## Please note

- The APKs are **debug-signed**, for academic demonstration and sideloading only. They are not Play Store ready. Android may show an unknown-app or Play Protect warning.
- Verified by static analysis (clean), 3,460 automated tests passed / 11 skipped / 0 failed, and live tests of the Showcase AI path. **Not** tested on a physical Android phone; signed-in backend paths were not verified live.
