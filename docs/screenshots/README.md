# Screenshots

The images in this folder are used by the main [README](../../README.md). They are **renders of the real Atlas screens in Showcase Mode**, produced by running the application's own widgets at a phone-sized viewport (390 x 844 logical pixels) with the Roboto font. They are not photographs of a phone, and the content is Showcase sample data.

| File | Screen |
|---|---|
| `login.png` | Login with the "Explore in Showcase Mode" entry |
| `home.png` | Home with the Showcase banner |
| `workouts.png` | Workouts and the 30-day challenge |
| `nutrition.png` | Nutrition dashboard |
| `meal_prep.png` | Meal prep and recipes |
| `ai_coach.png` | AI Coach screen with a bundled sample conversation (the banner "AI is not set up in this build" appears because the rendering environment has no backend settings compiled in; it is not a live AI answer) |
| `health_wearables.png` | Health and Wearables |
| `hydration.png` | Hydration |
| `cardio_activity.png` | Cardio and activity |
| `community.png` | Community hub |
| `ranked.png` | Ranked |
| `profile.png` | Profile |

Device screenshots from a physical phone have not been added; see the known limitations in the README.
