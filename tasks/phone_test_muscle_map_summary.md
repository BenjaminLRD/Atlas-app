# Phone check: muscle map and workout summary

Automated tests cover the logic and the widgets. They do not prove any of this
on a real phone. Check by hand on the installed APK.

## Muscle map
- [ ] Workouts tab: a "MUSCLES TARGETED" card with the body figure sits under today's workout card; Review & Start still works.
- [ ] Highlighted muscles match the day (a push day lights chest, shoulders, triceps).
- [ ] Front / Back buttons switch the figure; an exercise that only shows on one side (e.g. Leg Extension) shows no buttons.
- [ ] "See muscles by exercise" opens a sheet; choosing one exercise changes the map; "Whole workout" restores it.
- [ ] Open any exercise from the library: its own "MUSCLES WORKED" map is shown.
- [ ] Weekly plan: "View muscle map" appears on days with exercises.
- [ ] Smallest phone you have: nothing overflows, the figure is big enough to read.

## Summary
- [ ] Finish a workout: the summary opens with name, date, times, duration, sets and exercises.
- [ ] Bodyweight-only workout: Total volume shows a dash, not 0 kg.
- [ ] A first-ever workout shows no PR tile.
- [ ] Beat a previous best: a gold PR tile and a PR list appear.
- [ ] After a second day in a row the streak tile reads "2 days".
- [ ] Finish returns to the app as before; the workout is in history once.
